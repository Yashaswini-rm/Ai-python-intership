# AI Study Assistant

## About the Project

The AI Study Assistant is a beginner-friendly Python project designed to help students learn basic concepts of Python, Artificial Intelligence, Machine Learning, Pandas, and NumPy.

## Features

- Answers basic study questions
- Uses TF-IDF for text representation
- Uses Cosine Similarity to find the most relevant question
- Interactive question-and-answer system
- Provides a response when a question is not recognized

## Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity

## How It Works

The user's question is converted into a numerical representation using TF-IDF. The system compares it with the stored questions using Cosine Similarity and returns the answer associated with the most similar question.
